# Hostel Management App

A dashboard concept for managing hostel operations.

## Core Modules

- Dashboard overview
- Student management
- Room & seat management
- Fees & payments
- Complaints
- Notices
- Attendance / visitors
- Food / meals
- Quick actions

## Figma Practice

I used this design to practice dashboard information architecture, reusable cards, status badges, Auto Layout, spacing consistency, and presenting a large amount of information without losing hierarchy.
