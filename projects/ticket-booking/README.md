# Flight / Bus Ticket Booking App

A travel booking dashboard concept supporting flight and bus journeys.

## Core Modules

- Search / book ticket
- My bookings
- My tickets
- Payment history
- Notifications
- Saved routes / favorites
- Profile
- Help & support

## Figma Practice

I used this design to practice search-first UX, reusable booking cards, status variants, Auto Layout, notification hierarchy, navigation, and a complete booking-to-ticket user flow.
